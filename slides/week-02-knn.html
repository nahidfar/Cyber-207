CYBER 207 · KNN · 2
Intuition

A new event inherits local evidence

Suppose a new authentication session arrives. We compare it with labeled historical sessions.

  1. Represent each session as a feature vector.
  2. Compute distance to stored examples.
  3. Select the closest $k$.
  4. Aggregate their labels.

Lazy learning

KNN does not fit a compact equation during training. It stores examples and postpones most work until prediction.

Cheap fit · expensive query · memory-heavy

CYBER 207 · KNN · 5
Distance

Euclidean distance: straight-line separation

d(x,z) = √[ ∑j=1p (xj − zj)² ]

Example

Query: $(2,4)$
Stored point: $(5,8)$

$d=√((2−5)^2+(4−8)^2)=5$

Question before calculation

Can we meaningfully add squared differences in failed logins, request counts, and geographic distance?

Units encode priorities unless we control them.

CYBER 207 · KNN · 6
Metric choice

Different distance functions create different neighborhoods

MetricDefinitionGeometric intuitionSecurity consideration
Euclidean ($L_2$)$√∑|x_j-z_j|^2$Round neighborhoodsLarge differences receive extra weight
Manhattan ($L_1$)$∑|x_j-z_j|$Diamond neighborhoodsOften less dominated by one extreme difference
Minkowski ($L_p$)$(∑|x_j-z_j|^p)^{1/p}$Family containing both$p$ is a hyperparameter
Cosine distance$1−(x·z)/(||x||||z||)$Angle, not magnitudeUseful for sparse text or behavior proportions
CYBER 207 · KNN · 7
Preprocessing

Without scaling, units can hijack “nearest”

Raw values

failed attempts: $0…8$

request count: $20…2,000$

A difference of 300 requests can overwhelm every other feature.

Standardized values

z = (x − μtrain) / σtrain

Fit $μ$ and $σ$ on training data only; then transform validation, test, and production.

A pipeline prevents preprocessing leakage.

CYBER 207 · KNN · 8
Hyperparameter

$k$ controls flexibility

Very small $k$

Jagged boundary, sensitive to noise and mislabeled points.

Lower bias · higher variance

Moderate $k$

Local patterns survive while isolated points have less control.

Select on validation evidence

Very large $k$

Boundary becomes smooth and drifts toward the majority class.

Higher bias · lower variance

Odd $k$ can reduce ties in binary classification, but does not solve class imbalance.

CYBER 207 · KNN · 10
Voting

Not every neighbor must have equal influence

Uniform vote

vote weight = 1

Simple and stable, but the first and kth neighbor count equally.

Distance-weighted vote

vote weight ≈ 1 / (d + ε)

Closer examples matter more. Exact duplicates require careful handling.

A vote fraction is not automatically a calibrated probability.

CYBER 207 · KNN · 11
Imbalanced security data

Accuracy can conceal a failed review queue

Imagine 1,000 sessions:

  • 950 routine
  • 50 truly review-worthy
  • Model predicts every session as routine
accuracy = 950 / 1000 = 95%

But for the review class

Recall = 0%

Precision = undefined / no alerts

Operational value = none

Report the confusion matrix, precision, recall, PR-AUC, and queue volume.

CYBER 207 · KNN · 12
Thresholds

Classification is also a capacity decision

Distance-weighted neighbor votes produce a score. A threshold turns that score into a queue.

Lower threshold

More recall
More analyst load

Higher threshold

More precision
More missed cases

Choose with costs

Use validation data, analyst capacity, and false-negative consequences.

Never tune a threshold on the final test set.

CYBER 207 · KNN · 13
Dimensionality

In many dimensions, everything can look far away

Curse of dimensionality

  • Volume grows rapidly with dimensions
  • Data become sparse
  • Nearest and farthest distances become less distinguishable
  • Irrelevant features dilute meaningful similarity

Mitigations

  • Remove unavailable or irrelevant features
  • Use domain-grounded representations
  • Apply PCA or feature selection carefully
  • Collect more representative data
  • Validate the metric empirically

Complexity

“No training” does not mean “free”

StageBrute-force behaviorConsequence
FitStore $n$ examples with $p$ featuresFast, but memory is $O(np)$
One queryCompute distances to many/all examplesAbout $O(np)$ before selection
Index structuresKD-tree / ball treeCan help in low-to-moderate dimensions
Approximate searchTrade exactness for latencyUseful at scale; measure recall and security impact

Behavior drift also makes stale stored examples operationally expensive.

CYBER 207 · KNN · 15
Security failure modes

The neighborhood is an attack and quality surface

Data risks

  • Duplicate records dominate votes
  • Poisoned labels alter local neighborhoods
  • Historical bias defines “normal”
  • Post-incident fields leak outcomes

Evasion and drift

  • Small feature changes cross local boundaries
  • New infrastructure has no good neighbors
  • Seasonal behavior changes distance distributions
  • Missing values change comparability

Controls: provenance, deduplication, time-aware validation, drift monitoring, abstention, and analyst review.

CYBER 207 · KNN · 19
Takeaways

KNN is simple—and therefore revealing

  • A prediction is a local vote over stored examples.
  • Features, scaling, and metric define “near.”
  • $k$ controls the bias–variance tradeoff.
  • Validation chooses settings; test estimates once.
  • Security evaluation must reflect imbalance and analyst capacity.
  • High-dimensional, stale, duplicated, or poisoned data break neighborhoods.
  • Similarity supports triage; it does not prove intent.
One-sentence test: Can you explain why these exact records became the neighbors of this exact query?
