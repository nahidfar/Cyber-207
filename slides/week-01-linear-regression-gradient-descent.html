CYBER 207 · Regression · 3
Part I

The regression model

A line summarizes how the expected target changes with a feature.

CYBER 207 · Regression · 4
One feature

Slope and intercept define every prediction

$\hat y=wx+b$

Slope $w$

Predicted change in $y$ for a one-unit increase in $x$.

If $w=0.28$, one extra queued incident is associated with 0.28 predicted hours.

Intercept $b$

Prediction when $x=0$. It anchors the line but may lack operational meaning if zero lies outside the observed range.

Association is not causation.

CYBER 207 · Regression · 6
Residuals

Error has direction

$e_i=y_i-\hat y_i$

$e_i>0$

The model underpredicted. Actual investigation time was higher.

$e_i<0$

The model overpredicted. Actual time was lower.

Desired pattern

Residuals scatter around zero without curves, funnels, or time patterns.

Residual analysis asks how the model is wrong, not merely how much.

CYBER 207 · Regression · 7
Loss functions

Different summaries value mistakes differently

Mean absolute error

$MAE=\frac1n\sum|y_i-\hat y_i|$

Same units as the target; each additional error unit costs linearly.

Mean squared error

$MSE=\frac1n\sum(y_i-\hat y_i)^2$

Large misses receive disproportionate weight; units are squared.

Use RMSE, $\sqrt{MSE}$, to return to target units.

CYBER 207 · Regression · 8
Baseline

A model must beat a simple guess

Training-median baseline

Predict the same training median for every new record. It ignores features but is robust and hard to accidentally overfit.

Baseline MAE: 17.8 min
Regression MAE: 9.2 min

Why compare?

  • Proves features add predictive value
  • Exposes deceptive metrics
  • Sets a minimum operational standard
  • Keeps complexity accountable
CYBER 207 · Regression · 9
Multiple regression

One weighted contribution per feature

$\hat y=w_1x_1+w_2x_2+\cdots+w_px_p+b=\mathbf w^\top\mathbf x+b$

Conditional interpretation: $w_j$ is the predicted change in $y$ for a one-unit change in $x_j$, holding other modeled features fixed.

Numerical inputs may need scaling. Categorical inputs need an encoding such as one-hot indicators.

Correlated predictors can make individual coefficients unstable even when predictions remain useful.

CYBER 207 · Regression · 10
Geometry

Linear in parameters—not necessarily raw inputs

Still linear regression

$\hat y=b+w_1x+w_2x^2$

Polynomial features bend the curve, while the prediction remains linear in $w_1,w_2$.

Interactions

$\hat y=b+w_1x_1+w_2x_2+w_3x_1x_2$

The effect of one feature now depends on another. Add only with operational justification.

Feature engineering expands what the line can represent—and expands leakage risk.

CYBER 207 · Regression · 11
Part II

Gradient descent

Learning means searching parameter space for values that minimize loss.

CYBER 207 · Regression · 12
Objective

Turn fitting into minimization

$J(w,b)=\frac1n\sum_{i=1}^n(wx_i+b-y_i)^2$

Parameter space

Each point $(w,b)$ describes one candidate line and has one loss value $J(w,b)$.

Goal

Find parameters at the bottom of the bowl. For ordinary least squares, the surface is convex.

The model is $\hat y=wx+b$. The objective tells the learning algorithm what “better” means.

CYBER 207 · Regression · 13
Gradient

The gradient points uphill

$\frac{\partial J}{\partial w}=\frac2n\sum x_i(\hat y_i-y_i)$
$\frac{\partial J}{\partial b}=\frac2n\sum(\hat y_i-y_i)$

Interpretation

Each partial derivative asks: if this parameter increases slightly, how does loss change?

The gradient combines all partial derivatives into the direction of fastest local increase.

CYBER 207 · Regression · 14
Update rule

Move opposite the gradient

$\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t)$
Forward pass
compute $\hat y$
→
Loss
compute $J$
→
Gradient
compute slopes
→
Update
change $w,b$

$\eta$ is the learning rate. Repeat until loss stabilizes, gradients are small, or a validation-based stopping rule fires.

CYBER 207 · Regression · 16
Learning rate

Step size changes the optimization story

Too small

Stable but slow; may require many iterations and compute.

$\eta=0.005$

Useful

Loss falls smoothly and reaches the valley efficiently.

$\eta=0.08$

Too large

Oscillation, overshoot, or divergence; loss may explode.

$\eta=1.05$

A constant learning rate does not imply constant parameter movement: gradients shrink near the minimum.

CYBER 207 · Regression · 17
Feature scaling

Scaling reshapes the loss surface

Different scales

One feature ranges $0…10$; another $0…100{,}000$. The loss valley can become long and narrow, causing zig-zag updates.

Standardization

$z=(x-\mu_{train})/\sigma_{train}$

Comparable scales often make optimization better conditioned. Fit the scaler on training data only.

Closed-form ordinary least squares does not need gradient descent, but scaling remains useful for regularization and interpretation.

Batch choices

How much data estimates each gradient?

MethodExamples per updateBehaviorTradeoff
Batch GDAll training rowsStable, deterministic gradientExpensive on large data
Stochastic GDOne rowNoisy, frequent updatesCan wander; streams naturally
Mini-batch GDSmall subsetVectorized with manageable noiseStandard in deep learning

Shuffle training batches carefully; preserve time semantics when online order matters.

CYBER 207 · Regression · 19
Regularization

Penalize coefficients to trade variance for bias

Ridge ($L_2$)

$J_{ridge}=MSE+\alpha\sum_j w_j^2$

Shrinks correlated or noisy coefficients; usually retains all features.

Lasso ($L_1$)

$J_{lasso}=MSE+\alpha\sum_j|w_j|$

Can drive coefficients to exactly zero; selection may be unstable among correlated indicators.

Choose $\alpha$ with validation—not the final test set.

CYBER 207 · Regression · 22
Diagnostics

Residual patterns reveal model mismatch

Curve

Expected relationship is nonlinear; add justified transformations or a nonlinear model.

Funnel

Error variance grows with predictions; uncertainty is not constant.

Time drift

Residuals shift by week or deployment period; behavior or process changed.

Also compare residual distributions by severity, environment, region, and other operationally relevant groups.

CYBER 207 · Regression · 24
Failure modes

How a good-looking regression becomes unsafe

Evaluation failures

  • Post-closure fields leak the target
  • Related incidents cross partitions
  • Test data guides repeated tuning
  • No median/mean baseline
  • Only training loss is reported

Interpretation failures

  • Coefficient presented as causal
  • Extrapolation beyond observed range
  • Aggregate MAE hides high-severity misses
  • Drift ignored after deployment
  • Prediction treated as certainty

Takeaways

Model, objective, optimizer, evaluation

  • Linear regression maps features to a numeric prediction.
  • Residuals preserve the direction of mistakes.
  • MAE and MSE encode different error priorities.
  • Gradient descent moves opposite the loss gradient.
  • Learning rate controls update size.
  • Scaling can improve optimization geometry.
  • Validation guides choices; test estimates once.
  • Low loss does not establish causality or safety.
Core test: Can you explain what is predicted, how loss is computed, how each parameter changes, and which errors matter operationally?
