Before class

  • Use Python with NumPy, pandas, Matplotlib, and scikit-learn.
  • Restart the kernel and run all cells in order. The random seed is fixed at 207.
  • Frame the target as investigation minutes, not attacker guilt or analyst quality.
  • Keep the regression lesson open beside the notebook for the equation and interactive descent demonstration.
Opening question: If an alert has twice as many events, should investigation time double? Use answers to distinguish a useful linear approximation from a causal law.

Teaching sequence

Cells 1–3 · 8 minutes

Define the model, loss, and update rule

Read ŷ = wx + b aloud: slope converts standardized event count into predicted minutes; intercept is the prediction at zero standardized events. MSE aggregates squared residuals. The negative gradient points downhill.

Ask: Why square errors? What operational behavior might make MAE preferable?
Cells 4–5 · 8 minutes

Generate data with a known mechanism

Students can see that event count, affected hosts, and severity create the target before noise is added. This gives a rare opportunity to compare what the model learns with known ground truth.

Ask: Which columns are available when an alert arrives? Name a post-investigation field that would leak the answer.
Cells 6–7 · 12 minutes

Implement gradient descent

Trace one loop: predict → residual → loss → gradients → parameter update. Emphasize that StandardScaler is fit only on training features.

error = prediction - y
dw = 2 * mean(x * error)
db = 2 * mean(error)
w -= learning_rate * dw
b -= learning_rate * db
Observe: the one-feature model learns approximately w=1.393, b=58.349, with test MAE near 17.81 minutes. Weak performance is expected because hosts and severity were omitted.
Cells 8–10 · 18 minutes

Watch learning in data and parameter space

In data space, each snapshot is a candidate line. In parameter space, each point is a candidate pair (w,b); contours join candidates with equal loss.

Pause at step 0: Why is the line horizontal at zero? Why are early arrows long while later arrows shrink even though the learning rate is fixed?

Connect the two visuals explicitly: every move on the contour plot produces a new line in the six-panel plot.

Cells 11–13 · 10 minutes

Read convergence and stress the learning rate

The loss curve should fall rapidly and then flatten. Compare rates 0.005, 0.08, and 1.05 on a logarithmic y-axis.

Ask: Does a flat loss curve prove good generalization? Does a near-zero gradient imply zero residuals?
Cells 14–17 · 15 minutes

Move to a production-shaped pipeline

The ColumnTransformer scales numeric fields and one-hot encodes severity. Ridge regularization stabilizes coefficients. Compare against the training-median baseline before interpreting the model.

Expected comparison: baseline MAE 17.836, RMSE 21.90, R² -0.019; Ridge MAE 9.224, RMSE 11.64, R² 0.712.
Ask: What does negative baseline R² mean? In the residual plot, what pattern would suggest the model missed nonlinearity or a subgroup?

Troubleshooting

  • Loss explodes: lower the learning rate and confirm the feature was standardized.
  • Shape/type error in the loss surface: rerun in order; the visualization intentionally converts the target to the NumPy array y_visual.
  • Different numbers: restart and run all; confirm RANDOM_STATE = 207.
  • Missing style: upgrade Matplotlib or replace seaborn-v0_8-whitegrid with an available style.

Extensions and exit ticket

  1. Predict what changes when the learning rate doubles, then test.
  2. Add event_count * affected_hosts without touching the test partition during design.
  3. Report MAE by severity and discuss asymmetric underestimation cost.
  4. Sketch residual patterns for omitted severity, nonlinearity, and changing variance.
Exit ticket: In one sentence each, distinguish a residual, a gradient, a learning rate, and a test metric.
