Opening and data quality

10 minutes · Data creation

Separate evidence from identifiers and outcomes

The notebook creates 1,200 time-ordered network events with timestamps, network fields, missing values, outliers, and an imbalanced synthetic target.

Ask: Which columns describe the event, which identify it, and which exist only after investigation?
Expected: event_id invites memorization; investigation_result leaks the label; bytes are long-tailed; missing duration is associated with UDP collection.
8 minutes · Quality inspection

Missing is not zero

Use the schema, missingness, summary statistics, and plots to distinguish data defects from meaningful absence. Missing duration may reflect protocol behavior, sensor coverage, or processing failure.

Construct defensible features

18 minutes · Feature construction
FamilyTeaching emphasis
TimeCyclic encoding keeps midnight close to 23:00.
NetworkIPs and ports have structure; they are not ordinary numbers.
RatesEvery denominator needs an explicit zero and missing-value policy.
HistoryA row can use prior events, never itself or future events.
Draw: the open-left trailing window and show why the current event is appended only after its feature values are recorded.
10 minutes · Learned transformations

fit learns; transform applies

Imputation learns training medians, encoding learns categories and order, and scaling learns center and spread. Frozen state transforms validation, test, and production rows.

Discuss: The unknown-category example produces an all-zero one-hot row. When would an explicit unknown indicator be preferable?

Make leakage visible

8 minutes · Leakage demonstration

The valid model should have modest average precision. The deliberately invalid future-outcome model reaches 1.000.

Ask: Did feature engineering improve the model?
Answer: No. It invalidated the question. A perfect result from post-outcome information is evidence of leakage.

Pipeline, evaluation, and selection

12 minutes · Pipeline and evaluation

Trace one numeric and one categorical field through the ColumnTransformer. Read precision, recall, average precision, ROC-AUC, and the thresholded confusion matrix as operational evidence.

Ask: Which error consumes analyst capacity? Which misses a review-worthy event? Who owns the threshold decision?
10 minutes · Comparison and selection

Read every chronological fold, not only the mean. Treat mutual information, correlation, and permutation importance as distinct diagnostics.

Correction: Importance measures model reliance under this dataset and scoring setup. It does not establish causation or safety.
10 minutes · Production surprises

The unseen categories and missing duration should still produce a finite probability. Successful execution proves compatibility, not prediction quality. Monitor novelty, missingness, freshness, and score drift.

Validate the feature contract

7 minutes · Tests and exit ticket

Run the assertions for schema, determinism, missing values, zero denominators, unknown categories, time boundaries, and forbidden fields.

Expected anchors: all feature-contract checks pass; leaked AP is 1.000; held-out engineered AP is approximately 0.38 with seed 207.
Exit ticket: Define one feature’s entity, timestamp, window, null behavior, expected range, owner, drift monitor, and offline/online parity test.
